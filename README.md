## Quickstart

Access the platform directly in your browser—no local installation or setup required.

1. Go to [survive-uem.com](https://survive-uem.com).
2. Click **Get Started** or **Sign In** using Google or GitHub.
3. Access your dashboard and features immediately.

## FAQ

<details>
<summary>Is Survive UEM free to use?</summary>

The core platform features are accessible upon sign-up. Specific tier limits or subscriptions depend on your account level.
</details>

<details>
<summary>Do I need to install anything locally?</summary>

No. Survive UEM is entirely web-based and runs directly inside any modern web browser.
</details>

<details>
<summary>How is my authentication handled?</summary>

Authentication is powered securely via standard OAuth providers (Google, GitHub). We do not store plain-text credentials.
</details>
